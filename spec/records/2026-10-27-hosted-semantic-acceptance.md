refresh but does not configure the actual semantic model. Generic five-model
source qualification and Desktop's actual-model IPC receipt do not prove the
HTTP encoding and admitted hosted database provider. No existing hosted-model
scenario was found during this audit; this is an acceptance gap rather than an
invented failing product assertion.

The new opt-in scenario enters through the retained login, obtains an admitted
client and uses the real HTTP provider. It compares six 384-dimensional vectors,
fingerprints and all six query rankings with the already qualified Linux CPU
reference at the unchanged 1e-5 vector and 2e-4 ranking tolerances. It verifies
actual model/runtime cache bytes, detach/reopen, cold offline reuse, read-only
query revisions and unchanged vault files. The current Search UI/selection
journey remains in the same configuration and must also pass.

Unknown CPU, platform or reference hashes fail closed. The ordinary browser lane
reports this expensive model case as an explicit opt-in skip; actual R3 closure
requires its separate passing receipt.
