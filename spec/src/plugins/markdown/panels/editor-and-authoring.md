# Markdown Panels / Editor and authoring

## LN-MD-021 — Package: export app-only FileProperties, Outline, Backlinks, and OutgoingLinks

<a id="ln-md-021"></a>

**Requirement.** The package MUST export app-only `FileProperties`, `Outline`, `Backlinks`, and `OutgoingLinks` Svelte components. Backlinks and Outgoing Links MUST fix their mode in those public wrappers; their shared mode selector remains private.
